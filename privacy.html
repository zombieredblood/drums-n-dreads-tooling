Privacy Policy

Drums N Dreads Tooling · Last updated: 7 October 2026

Drums N Dreads Tooling (“the app”) is a personal, self-hosted application operated by its owner for the sole purpose of uploading the owner’s own videos to the owner’s own YouTube channels. It is not a commercial product and is not made available to other users.

Information the app accesses

With the owner’s explicit consent through Google OAuth, the app uses the YouTube Data API to access the owner’s own YouTube account in order to: list the owner’s channels, upload videos, and set video thumbnails and metadata. The app only ever acts on the account of the person who signs in.

How information is used

Access is used exclusively to publish the owner’s own content to the owner’s own channels. The app does not use this access for advertising, profiling, or any purpose other than the upload workflow described above.

Data storage and sharing

The app runs locally on the owner’s own computer. OAuth tokens are stored locally on that machine solely to maintain the sign-in session. No user data is collected from third parties, sold, or shared with anyone. The app has no server and transmits data only to Google’s official APIs.

Google API Services User Data Policy

The app’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke the app’s access at any time at myaccount.google.com/connections.
